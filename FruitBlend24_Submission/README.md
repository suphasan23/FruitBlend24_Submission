# FruitBlend24 — Revenue & Operations Analyst Case

แอป Python สำหรับวิเคราะห์ยอดขาย กำไร ราคา โปรโมชัน และแผนสต็อก พร้อมข้อมูลผลลัพธ์และคู่มือนำเสนอภาษาไทย

## เริ่มใช้งานใน 1 นาที

1. แตก ZIP ทั้งโฟลเดอร์ก่อน อย่าเปิดไฟล์จากภายใน ZIP
2. เปิด PowerShell ในโฟลเดอร์ `FruitBlend24_Submission`
3. ใช้ Python 3.12 ขึ้นไป แล้วรัน (ตรวจส่วนแอปกับ Python 3.14 ของเครื่องนี้ด้วยแล้ว):

```powershell
python app.py
```

เปิดเบราว์เซอร์ที่ **http://127.0.0.1:8765** และกด Ctrl+C ในหน้าต่าง PowerShell เมื่อต้องการหยุด

การเปิดแอปเพื่อดูผลที่แนบมา **ใช้เฉพาะ Python standard library ไม่ต้องติดตั้งแพ็กเกจเพิ่มหรือเชื่อมต่ออินเทอร์เน็ต** หากเครื่องใช้ Python Launcher ให้ใช้ `py -3.12 app.py` แทนได้

หากพอร์ตถูกใช้อยู่:

```powershell
python app.py --port 8766
```

## สิ่งที่ส่งมอบ

- `app.py` — เว็บแอป Python และ API คำนวณสถานการณ์/สต็อก
- `dashboard.html` — ส่วนแสดงผลภาษาไทย กราฟและตาราง ไม่มี CDN หรือ external font
- `analysis.py` — pipeline อ่าน Excel ทำความสะอาด คำนวณ P&L ประเมินโปร และ forecast
- `data/` — สำเนาไฟล์ต้นฉบับ Excel และ Word โดยไม่เปลี่ยนข้อมูล
- `results/` — CSV รายละเอียด, JSON ผลวิเคราะห์, แถวที่ตัดออก และผลตรวจสอบ
- `EXECUTIVE_SUMMARY_TH.md` — ข้อค้นพบและข้อเสนอแนะพร้อมตัวเลข
- `PRESENTATION_TH.md` — บทพูด 10–12 นาที พร้อมคำอธิบายและคำถามที่อาจถูกถาม
- `METHODOLOGY.md` — สูตร วิธีทำ สมมติฐาน และข้อจำกัด
- `SUBMISSION_NOTE.md` — บันทึกวิธีทำงานสำหรับแนบส่ง
- `tests/` — ทดสอบสูตรการเงิน การปรับสมมติฐาน สต็อก และการป้องกันข้อมูลอนาคตรั่วเข้าโมเดล

## ลำดับอ่านเพื่อเตรียมนำเสนอ

อ่าน Executive Summary ก่อน จากนั้นเปิดแอปตามบทใน Presentation และใช้ Methodology เตรียมตอบคำถามเชิงเทคนิค

ในแอปมี 7 หน้า: ภาพรวมผู้บริหาร / กำไรและยอดขาย / ราคาและเมนู / โปรโมชัน / คาดการณ์และสต็อก / ข้อมูลและดาวน์โหลด / วิธีนำเสนอ

ตัวกรองเดือนและครัวใช้เฉพาะภาพรวมกับกำไร ส่วนราคาจะใช้ต้นทุนล่าสุด โปรโมชันใช้ทั้งช่วงข้อมูล และ forecast ใช้วันที่ตัดข้อมูล 31 สิงหาคม 2026 ซึ่งระบุไว้ในแต่ละหน้า

## รันการวิเคราะห์ใหม่ตั้งแต่ Excel

ขั้นตอนนี้ต้องติดตั้ง dependencies หนึ่งครั้ง โดยการติดตั้งครั้งแรกต้องใช้อินเทอร์เน็ต:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe analysis.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe app.py
```

ถ้าแอปเปิดอยู่ขณะสร้างผลใหม่ ให้หยุดแล้วเปิดใหม่เพื่อโหลด JSON ล่าสุด คำสั่งนี้ใช้ข้อมูลต้นฉบับที่แนบใน `data/` และสร้างผลใหม่ใน `results/` เท่านั้น

แยกผลการรันเพื่อตรวจทานโดยไม่แทนที่ผลส่งงาน:

```powershell
.\.venv\Scripts\python.exe analysis.py --source data/FruitBlend24_Intern_Case_Data.xlsx --output results_review
```

เวอร์ชันที่ใช้สร้างผลวิเคราะห์และตรวจทั้งชุด: Python 3.12.14, pandas 3.0.1, NumPy 2.3.5, openpyxl 3.1.5

## ขอบเขตใช้งานจริง

แอปนี้ใช้งานได้ในเครื่องสำหรับตรวจเคส นำเสนอ และทดลองแผนธุรกิจ ข้อมูลทั้งหมดเป็นข้อมูลจำลอง ไม่ใช่ระบบสั่งซื้อหรือระบบบัญชีจริง

สูตรสต็อกให้หน่วยเทียบเท่าแก้ว ต้องเติมสูตรวัตถุดิบต่อแก้ว yield สต็อกตามอายุ ของระหว่างทาง และ lead time จริงก่อนใช้เป็นใบสั่งซื้อ ส่วนผลกำไรจากแผนทดลองเป็นผลแบบมีเงื่อนไข ไม่ใช่ผลที่ยืนยันว่าจะเกิดขึ้น

เซิร์ฟเวอร์เปิดเฉพาะ `127.0.0.1` ไม่ได้เผยแพร่สาธารณะ หากต้องเปิดใช้งานหลายคนผ่านอินเทอร์เน็ต ให้เปลี่ยนเป็น production server เพิ่ม HTTPS และการยืนยันตัวตน ตามข้อจำกัดของ [Python http.server](https://docs.python.org/3/library/http.server.html)
